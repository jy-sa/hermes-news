hermes-news 개인정보처리방침

최종 수정일: 2026-10-22

1. 사용자

hermes-news는 운영자 본인만 사용하는 개인용 도구입니다. 다른 사람의 Google 계정 데이터에는 접근하지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Gmail: 메일 읽기, 라벨 정리, 운영자가 요청한 메일 발송
  • Google 캘린더: 일정 읽기와 운영자가 요청한 일정 등록·수정
  • Google Drive·문서·스프레드시트: 운영자가 요청한 파일 읽기·작성
  • 연락처(읽기 전용): 메일·일정 작업 시 받는 사람 확인
  • YouTube(읽기 전용): 운영자가 좋아요를 누른 영상의 제목

3. 사용 목적

위 데이터는 운영자 본인의 개인 비서 작업(메일·일정·문서 처리)과 개인 뉴스 브리핑의 관심사 추천에만 사용합니다. 광고, 판매, 프로파일링 목적으로 사용하지 않습니다.

4. 저장과 보관

  • 데이터는 운영자 소유 서버에만 저장되며, 접근 토큰은 운영자만 읽을 수 있는 파일에 보관합니다.
  • YouTube 좋아요 제목은 최근 7일분만 보관하고 그 이후 자동으로 삭제합니다.

5. 제3자 제공

Google 사용자 데이터를 제3자에게 판매하거나 제공하지 않습니다. 단, 운영자가 요청한 작업을 처리하기 위해 운영자가 선택한 AI 모델 제공자에게 해당 작업에 필요한 내용이 전달될 수 있습니다.

6. 권한 해제와 삭제

Google 계정 권한 페이지에서 언제든 접근 권한을 해제할 수 있습니다. 해제하면 서버에 저장된 토큰과 수집 데이터를 삭제합니다.

7. Google API 서비스 사용자 데이터 정책 준수

hermes-news의 Google API 데이터 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

8. 문의

이 저장소의 GitHub Issues 또는 Google 동의 화면에 표시된 지원 이메일로 문의할 수 있습니다.
